# Original fonts available offline

These files preserve the prototype's declared font families. Only the delivery location changed; the Tailwind font stacks and design tokens remain unchanged.

- Pretendard Variable v1.3.9: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable
- Nanum Pen Script: https://fonts.google.com/specimen/Nanum+Pen+Script
- Original font licenses accompany both files in this directory.

The application loads these assets locally. No external font stylesheet is required for the demonstration.
